## 2. Partition Details

### 🔐 LOGIN — `assets/js/auth.js` : `1-140`
**HTML:** `index.html` navbar `#login-btn` `#logout-btn` `#user-display` `#auth-badge` + overlay `#login-modal` + hint `#booking-login-hint`  
**CSS:** `assets/css/style.css` section `3. LOGIN MODAL`  
**Backend:** `api/login.php` + `api/logout.php`  
**State:** `assets/js/config.js` `currentUser`, `AUTH_STORAGE_KEY` (localStorage)  
**Flow:** `initAuth()` → `openLoginModal()` → `handleLogin()` POST `api/login.php` → store token → `updateAuthUI()` → `handleLogout()`. Booking (`booking.js:Next()`) blocks if `!isLoggedIn()` and reopens login.  
**Why needed:** original project had *no* login — you asked which part is login, so this partition was **created** as demo (any ID + ≥4-char password works offline; replace with real `users` table check in `api/login.php:18`).

### 💺 SEAT CHOOSING — `assets/js/seats.js` : `1-40`
**HTML:** `index.html` `#purchase-section` left column: grid `A1-J4` (40 seats) generated by `document.write` `rowLetters`, steering wheel icon, legend `Available/Selected`.  
**CSS:** `assets/css/style.css` section `6. SEAT BUTTON STATES` (`.seats`, hover/active/focus)  
**Helpers:** `assets/js/utils.js` `setSeatSelectedStyle()`, `setInnerText()`  
**State:** `config.js` `maxAllowedSeats=4`, `selectedSeatsList`, `availableSeat`, `bookedSeatIds`  
**Logic:** `initSeatSelection()` attaches `.seats` clicks → `handleSeatClick()` guards (already booked / disabled / duplicate / max 4) → updates counters `seats-left`, `selected-seat` → calls `addSeatToBookingList()` → `totalCost()` `grandTotalCost()` → `validateNextButton()`.  
**DB Sync:** `api.js` `loadBookedSeats()` paints booked red disabled from MySQL `trip_seats`.

### 🛣️ ROUTES / DESTINATION — `assets/js/routes.js`
**HTML:** `index.html` `#route-info-display` (hidden card `#route-title`, `#route-stops-list`) + desktop/mobile dropdowns `.route-select-btn`  
**Data:** `busRoutes` Dhanmondi/Mirpur/Signboard/Jatrabari/Palashi/Uttara each 7 stops  
**Flow:** `initRouteDropdown()` → click swaps `currentRoute`, resets seats/totals, `showRouteInfoCard()` + `updateShuttleInfoSection()` + `loadTripAndSeats()` for new `trip_id`.

### 🧾 BOOKING / CHECKOUT — `assets/js/booking.js`
**HTML:** `index.html` `#purchase-section` right column: `#booking-seat-container`, `#total-cost`, `#grand-total`, inputs `#passenger-name/phone/email`, `#next-btn`, `#booking-reference`  
**CSS:** `assets/css/style.css` sections `7. BOOKING SUMMARY LIST` + `7. NEXT BUTTON STATE`  
**Logic:** `initPassengerFormValidation()` → `validateNextButton()` (needs seat + name + phone) → `Next()` enforces `isLoggedIn()` + `!isBooking` + re-checks `bookedSeatIds` → POST `api/create_booking.php` JSON → on success marks seats red, `loadBookedSeats()`, shows `#successfull-section`.

### 🗺️ LIVE LOCATION — `assets/js/map.js`
**HTML:** `index.html` `#live-location-section` `#live-map` `.live-route-btn`, `#live-route-name`, `#live-location-status`, `#my-location-btn`, `#get-directions-btn`, `#stop-location-btn`  
**CSS:** `assets/css/style.css` section `9. LIVE LOCATION PANEL`  
**Lib:** Leaflet 1.9.4 + OSM tiles (no API key)  
**Data:** `liveRouteData` 6 colored polylines + `UIU_LOCATION` 23.7966,90.4495  
**Flow:** `initLiveMap()` → `showLiveRoute()` → `startLiveLocation()` watchPosition + `updateLiveUserLocation()` marker/circle → `centerOnMyLocation()` `getDirections()` `stopLiveLocation()`.

### 🧩 UTILS / CONFIG / API — Shared
- **Config:** `assets/js/config.js` single source for `API_BASE='api/'`, `SEAT_FARE=550`, trip/seat/auth state — load first.
- **Utils:** `assets/js/utils.js` pure DOM helpers only.
- **API:** `assets/js/api.js` `loadTripAndSeats()` `GET get_trip.php?route=&date=` → `loadBookedSeats()` `GET get_seats.php?trip_id=` — no UI except seat paint.
- **Entry:** `assets/js/app.js` *only* `DOMContentLoaded` → calls `initAuth()`, `initSeatSelection()`, `initPassengerFormValidation()`, `initRouteDropdown()`, `initLiveMap()`, `initLiveLocationButtons()`, `loadTripAndSeats()`. Order matters — see HTML script tags.

### 🎨 PRESENTATION — HTML + CSS
- **Hero:** `index.html` `.banner-hero` + CSS `4. HERO`
- **Shuttle Info Card:** `#display-route-name`, `#display-boarding-points`, `#seats-left`, 550 Taka — updated by routes+api.
- **Carousel:** 4 slides `pic-*.jpg` — no JS, DaisyUI.
- **Footer:** static.

### 🗄️ BACKEND — `api/`
| File | Method | Partition |
|------|--------|-----------|
| `config.php` | PDO `127.0.0.1/uiu_shuttle/root/''`, `json_input/response` | Shared |
| `get_trip.php` | `GET ?route&date` → `trip_id,fare` | API |
| `get_seats.php` | `GET ?trip_id` → 40 seats + `effective_status` | API / Seats |
| `create_booking.php` | `POST {name,phone,email,route,trip_id,seats[1..4]}` transactional `FOR UPDATE` | Booking |
| `login.php` | `POST {student_id,password}` demo token | **Login** |
| `logout.php` | `POST` stateless | **Login** |

### 🗃️ DATABASE — `uiu_shuttle`
`routes → trips → seats → trip_seats → passengers → bookings → booking_seats` (see `database/README.md` for DDL).
